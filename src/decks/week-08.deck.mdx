## Declare the equality convention

Flag when **score ≥ threshold**.

At threshold 50, a score of 50 is flagged.

A prediction is compared with the authored label to count an error. It does not create that label.

## Four questions, four denominators

Precision: **TP / (TP + FP)** — how many flags are correct?

Recall: **TP / (TP + FN)** — how many malicious cases are found?

False-positive rate: **FP / (FP + TN)** — how many benign cases are flagged?

Accuracy: **(TP + TN) / total** — how many labels agree?

---

**6 minutes.** Use TP 8, FN 2, FP 18 and TN 72.

---

## Answer · accuracy can hide every miss

Precision **30.8%** · recall **80%** · false-positive rate **20%** · accuracy **80%**.

Never flag: accuracy **90%**, recall **0%**, precision **undefined**.

No flags means a zero precision denominator. The workbook returns `null`.

## Answer · fewer flags, more misses

At 75: **TP 6 · FN 4 · FP 5 · TN 85**.

Precision **6/11 ≈ 54.5%**. Recall **6/10 = 60%**.

Relative to 50: **two more misses, thirteen fewer false alarms**.

Review load falls from 26 to 11. The value of that trade depends on stated costs and capacity.

---

## Raising a cutoff removes cases

For fixed rows, raising the threshold cannot increase TP or FP.

It can increase false negatives and reduce recall.

Precision need not rise at every cutoff: its numerator and denominator both change.

Our three rows demonstrate one fixture, not a universal monotonic precision rule.

---

## Write the loss function

**L = cFN × FN + cFP × FP.** Lower is better.

Use cFP = 1 and vary cFN. These are arbitrary error-cost assumptions.

The model omits ordinary review overhead, staffing and severity differences.

Retain total flags beside loss if review capacity matters.

## Answer · name the alternatives

**2cFN + 18 = 4cFN + 5**, so **cFN = 6.5**.

Both thresholds cost **31** at that tie.

That does not establish the best cutoff among every possible value.

## Precision depends on prevalence

Let p = prevalence, r = recall and f = false-positive rate.

Projected precision = **pr / [pr + (1 − p)f]**.

True flags contribute pr. False flags contribute (1 − p)f.

Transporting r and f into another population is an assumption to examine.

## Exercise · count a thousand cases

**5 minutes.** Hypothetical prevalence is **1%** in 1,000 cases.

Keep recall **80%** and false-positive rate **20%**.

Fill all four cells and calculate precision.

Explain why this is a projection rather than deployment evidence.

---

## Answer · the benign pool is much larger

Ten malicious cases: **TP 8, FN 2**.

990 benign cases: **FP 198, TN 792**.

Precision = **8/206 ≈ 3.88%**.

A changed population may also change recall and false-positive rate. Neither transported rate is measured here.

---

## Do not rename exploration “validation”

These scores are not calibrated probabilities.

Trying thresholds on the same authored rows is sensitivity analysis.

For an actual detector: develop a procedure, freeze it and evaluate on independent unseen labelled cases.

Missing or disputed labels need an explicit policy. This teaching parser rejects missing labels.

Assess transfer → **review**.

Timeout at 2 h → still **review**, underlying pending/no-reply.

Image non-match at 2.1 h → still **review**.

Assessments advance the original observation checkpoint. They never reset the send time or infer a motive.

## Make clearance an explicit record

Require **every open finding ID** and a **non-empty review note**.

Retain the resolved evidence for the authored trace.

Clearance reveals the latest underlying phase, which may now be replied.

The program checks the note exists; it cannot certify the reviewer's judgement or establish consent.
